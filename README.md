## 📖 About The Project

**Unit Converter** is a modern, responsive, and easy-to-use web application designed to make everyday unit conversions simple and efficient.

Whether you need to convert distances, weights, temperatures, or liquid volumes, this application provides instant and accurate results through a clean and intuitive interface.

Built entirely with **Vanilla JavaScript, HTML5, and CSS3**, the project requires no backend, database, or external JavaScript libraries. Everything runs directly in your browser.

## ✨ Key Features

- 🔄 **Multiple Conversion Categories** – Supports Length, Weight, Temperature, and Volume.
- ⚡ **Instant Conversion** – Calculates results immediately without page reloads.
- 🎨 **Modern User Interface** – Clean design with attractive colors, interactive elements, and smooth hover effects.
- 📱 **Fully Responsive** – Works smoothly on desktops, tablets, and smartphones.
- 🔢 **Accurate Calculations** – Uses standard mathematical conversion formulas.
- 🧭 **Easy Navigation** – Simple category tabs for a better user experience.
- 🚀 **Lightweight Performance** – Fast loading with minimal resource usage.
- 🔒 **No Backend Required** – All calculations happen locally in the browser.
- 🛠️ **No External Dependencies** – Developed using pure HTML, CSS, and JavaScript.

## 🔁 Supported Unit Conversions

| Category | Supported Units |
|---|---|
| 📏 Length | Centimeters (cm), Meters (m), Kilometers (km), Inches (in), Feet (ft), Yards (yd), Miles (mi) |
| ⚖️ Weight | Grams (g), Kilograms (kg), Ounces (oz), Pounds (lb) |
| 🌡️ Temperature | Celsius (°C), Fahrenheit (°F), Kelvin (K) |
| 🧪 Volume | Milliliters (ml), Liters (l) |

## 🚀 Getting Started

Follow these simple steps to download and run the project on your local computer.

### 1. Clone the Repository

```bash
git clone https://github.com/Lulieeliyas/Unit_Converter.git
```

### 2. Navigate to the Project Folder

```bash
cd Unit_Converter
```

### 3. Open the Application

Open `index.html` directly in your preferred web browser.

Alternatively, use Visual Studio Code with the Live Server extension.

**That's it!** Your Unit Converter application is ready to use. No installation or backend configuration is required.
