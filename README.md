# 📏 Unit Converter Tool

A clean, modern, and fully responsive web-based unit converter. This tool allows users to instantly convert values across multiple categories including Length, Weight, Temperature, and Volume. 

Built entirely with **Vanilla JavaScript, HTML5, and CSS3**, it requires no backend and runs directly in the browser.

## ✨ Features

*   **Multiple Categories:** Convert Length, Weight, Temperature, and Volume.
*   **Instant Calculation:** Fast and accurate conversions using pure JavaScript.
*   **Clean UI/UX:** A modern, user-friendly interface with active tab highlighting and hover effects.
*   **Fully Responsive:** The layout adjusts seamlessly to mobile phones, tablets, and desktop screens.
*   **No Dependencies:** No external libraries (like jQuery or React) required. Just pure web technologies.

## 🛠️ Supported Conversions

| Category | Available Units |
| :--- | :--- |
| **Length** | Centimeters (cm), Meters (m), Kilometers (km), Inches (in), Feet (ft), Yards (yd), Miles (mi) |
| **Weight** | Grams (g), Kilograms (kg), Ounces (oz), Pounds (lb) |
| **Temperature** | Celsius (°C), Fahrenheit (°F), Kelvin (K) |
| **Volume** | Milliliters (ml), Liters (l) |
